hexo-theme-yilia
================

Yilia 是为 [hexo](https://github.com/tommy351/hexo) 2.4+制作的主题。

本主题是 Yilia 主题的修改版。原版 [hexo-theme-yilia](https://github.com/litten/hexo-theme-yilia)

## 插件

主题需要使用的hexo插件
* hexo-generator-feed（rss订阅）
* hexo-generator-searchdb（文章全局搜索）
* hexo-generator-json-content（文章标题搜索）
* hexo-wordcount（字数统计）
* hexo-generator-index-pin-top（文章置顶，需要卸载hexo-generator-index）

## 配置

主题配置文件在主题目录下的`_config.yml`，请根据自己需要修改使用。
